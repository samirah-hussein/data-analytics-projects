# Titanic Survival Analysis

## Project Overview

This project explores the factors that influenced passenger survival aboard the Titanic.

## Tools Used

- Python
- Pandas
- Power BI
- Excel

## Analysis Process

1. Data cleaning
2. Exploratory data analysis
3. Data visualisation
4. Dashboard creation
5. Insight generation

## Key Questions

- Did passenger class affect survival?
- Did age influence survival outcomes?
- Were there differences between male and female passengers?

## Key Findings

- First-class passengers had higher survival rates.
- Female passengers were more likely to survive.
- Survival rates varied across age groups.
