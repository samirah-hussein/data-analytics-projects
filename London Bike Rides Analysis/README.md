# London Bike Sharing Analysis

## Project Overview

This project analyses London bike-sharing data from 2015 to 2017 to identify trends in bike usage and explore how weather conditions affect ride demand. Data was cleaned and transformed using Python before being visualised in an interactive Tableau dashboard.

## Tools Used

- Python
- Pandas
- Jupyter Notebook
- Tableau Public

## Objectives

- Analyse bike-sharing usage patterns over time
- Investigate the impact of weather conditions on bike demand
- Create an interactive dashboard for data exploration
- Apply data cleaning, transformation, and visualisation techniques

## Dashboard Features

- Dynamic moving average analysis
- Adjustable moving average duration
- Date range selection
- Total rides KPI
- Temperature vs Wind Speed heatmap
- Interactive visualisations

## Key Findings

- Bike usage generally increased during warmer weather conditions.
- Moderate temperatures were associated with the highest ride volumes.
- Ride demand varied considerably across different weather conditions.
- Seasonal trends showed higher bike usage during warmer months.

## Project Outcome

This project demonstrates the complete analytics workflow, including data acquisition, cleaning, transformation, visualisation, and dashboard development. The final dashboard allows users to interactively explore bike usage trends and weather impacts using dynamic filters and parameters.
