# Lego Sales Data Analysis (R)

## Overview
This project analyses a Lego sales dataset to identify which product themes generate the highest revenue. The analysis focuses on data cleaning, revenue calculation, and visualising sales trends to support business decision-making.

## Dataset
The dataset includes information on Lego products such as:
- Price
- Quantity sold
- Theme and subtheme

## Tools Used
- R
- tidyverse
- Data visualization

## What I Did
- Created revenue variable (price × quantity)
- Calculated total revenue by theme
- Identified highest-performing category
- Built visualizations for subtheme sales

## Key Findings
- Star Wars generated the highest revenue
- Some subthemes contributed more heavily than others

- Data cleaning
